# Card images

In compact technique and term cards, the image icon sits immediately before the
Kup badge in the upper-right controls. Hover, keyboard focus or a tap opens the
preview; multiple images cycle every 1.5 seconds with the current caption/source.
Escape dismisses a focused preview. Hovering an image shows the Korean technique
name and its meaning in the interface language. Missing images are skipped.

The With images view retains all available images below the header, together with
their captions and sources. Image and title data use the existing override-aware
catalogues; viewing a card does not modify saved overrides.
