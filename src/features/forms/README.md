# Form media

Form cards show one visual material at a time. When there are multiple materials,
use the tabs (or Left/Right, Home/End) to switch between the attributed diagram,
custom images and each video source. A single material has no tab strip.

The card's Maximize button opens all materials together in a scrollable full-window
view. Videos start only when played, avoiding simultaneous audio. Escape or Close
returns to the selected inline material. Diagram credits and custom-image captions
and sources are retained. Clip stills stay with their video rather than appearing
again as separate image tabs. Media comes from the existing catalogues and image
overrides; this presentation does not write saved content.
